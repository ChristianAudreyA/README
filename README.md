## Cara Menjalankan Program
1. Buka terminal di dalam folder proyek (`README`)
2. Jalankan perintah `npm install`
3. Kompilasi Typescript ke Javascript dengan `npx tsc`
4. Jalankan program dengan perintah `node dist/kasirMbakTika.js`
